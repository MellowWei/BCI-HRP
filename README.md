# Human Return Research

A user-centered HCI / UX design research view of the Human Return Protocol (HRP).

Live URL after deployment: **https://mellowwei.github.io/Human-Return-Research/**

---

## What this site is

This is the HCI / UX research-framing companion site to HRP. It re-tells HRP from the user's side — pain points, journey, design hypotheses, test plan, and validation metrics — using Design Thinking as the organizing structure.

It is **not** a replacement for any existing HRP site:
- `mellowwei.github.io/BCI/` — the theoretical body (kept untouched, stays as the artistic-philosophical core)
- `mellowwei.github.io/BCI/validation.html` — the scientific validation page (for lab collaboration)
- `mellowwei.github.io/Ai-Q-10/` — AiAiQ<10 operating portal
- `mellowwei.github.io/QualiaRhythmMatrix/` — LGS V8 methodology

Human-Return-Research is the **fifth interface** — built for HCI / UX / Learning Sciences / Design audiences.

---

## Visual identity

Deliberately the **opposite** of the BCI main site's cyber-dark aesthetic:

- Warm off-white paper (#faf8f4) instead of black
- Newsreader serif (academic editorial) instead of cyber sans
- JetBrains Mono for labels and numerals
- Single restrained accent: deep wine-red (#8b2635)
- Editorial asymmetric layout, generous negative space, paper grain texture
- Sticky top nav with anchor links

The contrast itself signals: **same project, two interfaces, two audiences**.

## Site structure

13 sections following Design Thinking sequence:

00. Overview
01. Empathize — who and what
02. Pain Points — 8 design gaps
03. Define — problem statement
04. HMW — 6 framing questions
05. User Journey — 6 stages of return
06. Ideate — pain points → features table
07. Prototype v0 — what's built / simulated / planned
08. Test — 4-phase research plan (Phases 0–3)
09. Design Validation Metrics — 10 UX metrics
10. Researcher — bio + IRB + AI disclosure
11. Tokyo Collaboration — EN / 中文 / 日本語
12. Final Judgment — why this layer matters

---

## Boundary statements (do not remove)

The site is explicit and consistent on:
- Does not claim clinical efficacy
- Does not claim treatment of ADHD / anxiety / trauma / any clinical condition
- Does not claim completed BCI functionality
- Does not claim proven neural regulation
- Frames HRP as early-stage, falsifiable, adaptive auditory-AI research prototype
- All user-experience claims explicitly framed as design hypotheses to be tested

## Deployment

1. Create a new GitHub repo: **`Human-Return-Research`** under `mellowwei`
2. Upload `index.html` (this file) to the root
3. Settings → Pages → Source: `main` branch / `/ (root)`
4. Wait 1–2 minutes for first build
5. Live at `https://mellowwei.github.io/Human-Return-Research/`
