LAB GATE // WHAT A LAB SHOULD KNOW FIRST

What is built, what is not claimed, what can be tested.

已建成什么、不声称什么、可以如何验证。

HRP is not presented as a completed medical device or validated BCI. It is a research prototype and design system that can be evaluated through user research, behavioral measures, wearable physiology, and eventually EEG/fNIRS collaboration.

HRP 不被呈现为已完成的医疗设备或已验证脑机。它是一个研究原型与设计系统，可通过用户研究、行为指标、可穿戴生理信号，并最终通过 EEG/fNIRS 合作进行验证。

DESIGN THINKING // UX RESEARCH // 用户中心设计研究

Begin with the user, not the device.

从用户开始，而不是从设备开始。

People do not lose productivity first. They lose access to themselves. HRP is reframed here as a user-centered Neuro-AI design research project: Empathize → Define → HMW → Journey Map → Ideation → Prototype → Test → Scientific Validation.

用户不是先失去生产力，而是先失去返回自己的入口。这里将 HRP 重写为以用户为中心的 Neuro-AI 设计研究项目：共情 → 定义 → HMW → 用户旅程 → 构思 → 原型 → 测试 → 科学验证。

EMPATHIZE // 共情

Target user

The target user is someone whose body, attention, and emotion have moved out of mutual reach: students, creators, neurodivergent users, overloaded knowledge workers, and people who need support before they can clearly name what they need.

目标用户是身体、注意力与情绪相互失联的人：学生、创作者、神经多样性用户、过载的知识工作者，以及在说清需求前就需要被接住的人。

DEFINE // 问题定义

Problem statement

Users experiencing attention/emotional fragmentation need a way to recognize and regulate their state without being diagnosed, shamed, or forced into productivity logic.

处于注意力/情绪碎裂状态的用户，需要一种方式识别并调节自己的状态，而不是被诊断、被羞耻化，或被迫进入生产力逻辑。

USER PAIN POINTS // 用户痛点

Eight design gaps current tools leave open.

现有工具留下的八个设计缺口。

These are design hypotheses to be validated through interviews, usability tests, and micro-pilot data.

这些不是已经证明的结果，而是需要通过访谈、可用性测试与 micro-pilot 数据验证的设计假设。

01

Fragmented Attention

注意力碎裂

“I open three apps and forget why.”
“我打开了三个 App，然后忘了为什么。”

Opportunity: sample rhythm-state, then offer one small return cue.

设计机会：采样节律状态，再给一个最小返回信号。

02

Emotional Overload

情绪过载

“Too much feeling, no entry point.”
“感受太多，没有入口。”

Opportunity: low-density rhythm before verbal labeling.

设计机会：先给低压节律，再进入语言命名。

03

Transition Failure

状态转换失败

“I cannot move from here to next.”
“我无法从这里转到下一个状态。”

Opportunity: transition protocols, not instant productivity demands.

设计机会：设计转换协议，而不是立刻要求产出。

04

Body-Signal Blindness

身体信号不可读

“I notice I’m tired only after I crash.”
“我撑不住以后才知道累。”

Opportunity: wearable cues with uncertainty, not scores.

设计机会：用不确定性标注的可穿戴反馈，而不是分数。

05

Shame-Based Productivity

羞耻驱动效率工具

“Every notification feels like evaluation.”
“每条通知都像评分。”

Opportunity: reflective feedback, no streaks, no public scoring.

设计机会：反思性反馈，无打卡暴政，无公共评分。

06

AI Without Somatic Context

没有身体语境的 AI

“AI answers a question my body cannot ask.”
“AI 回答了我身体问不出的问题。”

Opportunity: pair AI feedback with state sampling and rhythm context.

设计机会：让 AI 结合状态采样与节律语境。

07

Diagnostic Pressure

诊断压力

“I don’t want a label. I want to come back.”
“我不想要标签，我想回来。”

Opportunity: functional rhythm states, not medical identity labels.

设计机会：使用功能性节律状态，而非医学身份标签。

08

Fragmented Memory of What Helped

有效帮助无法被记住

“Something helped, but I cannot reconstruct it.”
“刚刚有东西帮到了我，但我记不住路径。”

Opportunity: Personal Rhythm Map and return logs.

设计机会：个人节律图谱与返回记录。

44271 NEURAL CUFF // PLANNED WEARABLE SENSING LAYER

The body sends the signal. The protocol returns the human.

身体发送信号。协议把人返回给自己。

44271 Neural Cuff is a planned wrist-worn neuro-somatic rhythm interface. It is placed on the inner wrist near the pulse line to read cardiovascular rhythm, electrodermal activity, temperature drift, and micro-motion, then return gentle haptic cues.

44271 Neural Cuff 是计划中的腕戴式神经—身体节律接口。它贴近内腕脉搏线，读取心血管节律、皮肤电、温度漂移与微运动，并返回温和触觉信号。

PPG / HRVEDATEMPERATUREIMUHAPTIC RETURNNOT A SMARTWATCH

Why inner wrist?

The inner wrist is private, pulse-readable, touch-sensitive, and symbolically closer to body return than public display.

内腕是私密、脉搏可读、触觉敏感的身体区域，在象征上更接近身体返回，而不是公共展示。

Scientific boundary

The current cuff is a concept and planned sensing layer. It is not yet a validated physiological or neural device.

当前袖环是概念与计划中的传感层，不是已验证的生理或神经设备。

VALIDATION PLAN // UX + SCIENTIFIC TESTING

Design validation before neural validation.

先做设计验证，再做神经验证。

The validation pathway separates user need, interface comprehension, behavioral change, physiological proxy, and neural mechanism. This prevents AI output or aesthetic strength from being mistaken for scientific evidence.

验证路径将用户需求、界面理解、行为变化、生理代理指标与神经机制分开，避免把 AI 输出或美学强度误认为科学证据。

SCIENTIFIC BOUNDARY // 科学边界

HRP / AiAiQ<10 is not a medical treatment, not a diagnosis tool, not a validated BCI, and not proof of neural regulation. It is a falsifiable adaptive auditory-AI research prototype with a planned validation pathway through self-report, behavior, physiology, and future neural measures.

HRP / AiAiQ<10 不是医学治疗、不是诊断工具、不是已验证 BCI，也不是神经调节已被证明的证据。它是一个可证伪的自适应声音-AI 研究原型，验证路径包括自评、行为、生理与未来神经指标。

HRP / AiAiQ<10 は医療・診断・検証済み BCI ではなく、神経調整の証明でもありません。自己報告、行動、生理、将来的な神経指標によって検証される研究プロトタイプです。
